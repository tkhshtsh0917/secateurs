# 評価状況と評価方針

[English](../evaluation.md) | 日本語

全体のベンチマーク検証は進行中です。この開発版では、JMTEB全体の集約スコア、普遍的な高速化、品質維持を主張していません。数値テストが確認するのは変換とシリアライズの性質であり、用途ごとの品質ではありません。この実験実装を確認したり、開発に参加したりするために、ベンチマークの完了を待つ必要はありません。

[実験記録](experiments.md)には、参照実験と完了した一部の比較ペアを、悪化した結果も含めて記載しています。このcheckoutからはまだ利用できない評価ツールや証跡についても明示しています。これは進捗記録であり、再現実験の完了報告やベンチマークの正式公開ではありません。残る再現性の作業は[ロードマップ](roadmap.md)を参照してください。

再現可能な評価のため、モデル・データセット・評価器のrevisionを固定します。校正データの由来、スコア計算方法、目標幅、回復学習の設定、seedを記録してください。学習・校正、開発時の選択、最終評価には、それぞれ別のデータを使用します。

元モデル、pruning直後、回復後のモデルを、トークナイザー、prompt、正規化、数値精度、attention backend、評価タスクの定義が同じ条件で比較します。タスクの網羅率とタスクごとの悪化を報告してください。一部タスクの結果は全体の集約スコアではありません。ランダム選択や重みによる選択、同程度の予算での回復学習が有用な対照条件です。

レイテンシーやスループットは品質とは別に測定します。ハードウェア、ソフトウェア、バッチサイズ、実際の系列長、ウォームアップ、反復回数、メモリーを記録してください。起動、読み込み、エンコード、結果保存の時間を区別します。バッチサイズを変えると浮動小数点出力が変わる場合があるため、結果や再開用checkpointには推論設定全体を識別情報として含めます。

データセットや派生モデルの重みを再配布する場合は、それぞれのライセンスを確認してください。生成物やベンチマークのキャッシュはソースの公開対象から除外します。
