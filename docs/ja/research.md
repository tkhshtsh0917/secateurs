# 研究の対象範囲とUltraBERTとの関係

[English](../research.md) | 日本語

secateursは、UltraBERT-inspired pruningを既存の埋め込みモデルへ応用する、初期段階の再現研究です。現在のプロトタイプはpruningと回復学習の流れの一部を試すもので、UltraBERTの事前学習を再現したり、論文の性能上の主張を実証したりするものではありません。

最終的には再利用しやすいpruningライブラリを目指します。ただし、これは開発目標であり、現在の対応範囲や成熟度を表すものではありません。[ロードマップ](roadmap.md)と[実験記録](experiments.md)も参照してください。

## 共通する考え方と現在の違い

どちらもエンコーダーの深さを保ち、前向き計算の活性値から重要度を推定し、選択した重みを再利用して、構造化pruningの後に教師との学習を行います。これらの考え方は先行するpruning・蒸留研究にもあり、UltraBERTやsecateurs独自の貢献ではありません。

| 項目 | UltraBERT v1 | 現在のsecateurs |
| --- | --- | --- |
| 出発点 | 1.3Bのエンコーダーを380M、さらに150Mへ圧縮 | 既存のModernBERT埋め込みモデル。参照実験はruri-v3-310m |
| 削る構造 | hidden channel、attention headまたはhead次元、FFNニューロン | FFN中間ニューロンのみ。残差の幅、attention、語彙、RoPE、poolingは維持 |
| FFN重要度 | ゲート適用後の活性値の大きさを系列内で平均し、バッチ方向にL2ノルムで集約 | 有効トークン全体で活性値の絶対値を平均。paddingを除き、入力中のpromptを含む |
| 圧縮の段階 | 1.3B→380Mと380M→150Mの両方でpruningと蒸留 | 参照実験は1段階のpruningと、任意の埋め込み回復学習 |
| 教師と模倣対象 | 両サイズとも元の1.3B教師の単語予測logitsを使い、KL損失で蒸留 | 元のSentence Transformerの最終文埋め込みを事前計算し、MSE損失で蒸留 |
| 学習目的 | 5%・50%マスク系列を4:1で混ぜ、別々のLM headを使用。5%側にKL、50%側に通常のMLM | MLM、マスク率の混合、複数LM head、マスク率に応じた蒸留は未実装 |
| 学習規模 | 2Tトークン。最終段階に32Kへのコンテキスト拡張を含む | 小規模な回復学習の参照実験。既存モデルの系列長上限を維持 |

UltraBERT側の記述は[論文v1のSection 4とAppendix A.2](https://arxiv.org/html/2610.15028v1)に基づきます。[公式モデルカード](https://huggingface.co/dmis-lab/UltraBERT-150M)にも教師、マスク率ごとの目的関数、幅の変更が説明されています。

集約方法が違えば、選ばれるニューロンも変わり得ます。また、トークン全体の平均では長い系列が短い系列より大きな重みを持ちます。前向き計算の活性値スコアを実装しただけで、論文の選択規則を再現したことにはなりません。

埋め込みMSEも知識蒸留ですが、論文のtoken-logit目的関数とは異なる信号を伝えます。回復学習のデータを増やすだけでは、現在の方式がUltraBERTと同じになるわけではありません。

## 主張できることと証拠

現状に合う説明は、**埋め込み回復学習サンプルを備えたUltraBERT-inspired FFN pruning**です。「UltraBERTの実装」「忠実な再現」「同等の結果」「一般的な品質維持」という主張は、現在の証拠を超えます。

[pruning仕様](pruning.md)は実装した変換を、[回復学習](recovery.md)はサンプルの損失と既定値を説明します。数値テストでは変換の正しさ、元モデルの保持、勾配、シリアライズを確認していますが、下流タスクの品質や推論性能の向上は実証しません。残る比較と報告の方針は[評価方針](evaluation.md)を参照してください。

hiddenやattentionのpruning、論文と同じスコア計算、token-logit蒸留を追加するには、それぞれ別の実装と検証が必要です。現段階ではUltraBERTの事前学習の全要素を再現することを約束していません。
