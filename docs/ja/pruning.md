# ModernBERTのFFN pruning仕様

[English](../pruning.md) | 日本語

hidden幅をH、中間幅をIとすると、ModernBERTの結合済み入力射影の形状は[2I, H]、出力射影は[H, I]です。入力の2つの分岐は、ゲートを介した要素ごとの乗算で結合されます。

残すニューロンのインデックス集合をSとすると、入力ではS行とS+I行を分岐の順序を保って残し、出力ではS列を残します。biasが存在する場合も対応する位置を揃えて変換します。目標中間幅は全層で共通ですが、選ぶインデックスは層ごとに異なって構いません。結果のモデルは標準の`intermediate_size`設定で表現します。この処理ではhidden幅、語彙、attention、RoPEを削りません。

`activation_scores`は、down projectionへ入るゲート適用後の活性値について、有効トークン上の絶対値平均を測定します。paddingは除きますが、入力に含まれるpromptは集計対象です。校正にはpaddingされた3次元の活性値とattention maskが必要です。処理中は一時的にdropoutを無効にし、正常終了・失敗のどちらでもhookを解除します。このスコアは代理指標であり、UltraBERTの集約方式の厳密な再現ではありません。方法上の違いは[研究上の比較](research.md)を参照してください。

`make_plan`は目標幅を検証し、スコアが同点の場合も決定的に順序を解決します。スコアを指定しなければ、seed付きのランダム選択を使用します。`prune_ffn`は計画を検証してからモデルをコピーし、変換します。optimizerの作成や、コンパイル・量子化・分散ラッパーの適用より前にpruningを実施してください。

テストでは、削除対象のゲート付きニューロンをゼロにした元サイズのモデルと比較します。連続していないインデックスも対象です。保存・再読み込み後の推論が、校正時に残ったオブジェクトへ依存しないことも確認します。

埋め込み次元が同じでも、座標や順位は変わり得ます。文書とクエリの両方を同じ生徒モデルでエンコードしてください。
