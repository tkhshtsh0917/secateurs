# ロードマップ

[English](../roadmap.md) | 日本語

プロジェクトはプロトタイプの段階です。UltraBERT-inspired pruningの実験を、研究用の手順を自力で組み直さなくても使える便利なライブラリへ育てることが目標です。以下は開発の方向と完了条件であり、公開日や品質維持・高速化を約束するものではありません。

## 1. 最初の変換処理を確立する

実装済みなのは、ModernBERTのFFN中間幅pruning、保存可能な層ごとの計画、活性値スコア、seed付きランダム選択、任意依存のSentence Transformersアダプター、標準形式でのモデル保存・読み込みです。

オフラインテストでは、元サイズの参照モデルとの数値的一致、元モデルの保持、勾配、不正入力の拒否、再読み込みを確認します。これは限定された変換仕様を確認するものであり、用途ごとの品質を実証するものではありません。

## 2. 実験を完了し、再現可能な形で公開する

下流タスクの品質と、ワークロードごとの性能評価を進めています。[実験記録](experiments.md)には、途中結果と悪化した結果を記載しています。

この段階の完了には、再現可能な評価用の実行手段を公開し、環境とデータのrevisionを固定し、タスクの網羅率を報告して、元モデル・pruning直後・回復後を同条件で比較することが必要です。ランダム選択と重みによる選択の対照条件、幅を変えた比較、反復実験も追加します。メモリーとエンコード時間は、モデル読み込み、データ読み込み、checkpoint保存と区別して報告します。

## 3. 対応範囲の一連の手順を使いやすくする

校正データから計画作成、pruning、任意の回復学習、検証、評価までの手順を文書化します。回復学習のうち再利用可能なAPIにすべき処理を見極め、適切な検証とレポート形式を整えます。サンプルを汎用的なrecipeと紹介する前に、モデル固有の前提を取り除きます。

完了条件は、新しい利用者が文書に沿って対応済みの手順を実行し、標準モデルを保存し、個別の研究スクリプトなしで利点と欠点を評価できることです。APIの安定化や対応範囲の拡大は今後の作業です。

## 4. 個別の証拠を伴うrecipeを拡張する

拡張候補には、論文どおりの重要度集約、hidden channelやattentionのpruning、ほかのエンコーダーへの対応、異なる蒸留目的関数があります。それぞれに仕様の文書化とテストが必要です。

token-logit蒸留やUltraBERTの混合マスク率による事前学習は、新たな学習機能の実装であり、現在の埋め込みMSEサンプルの名前を変えることではありません。より忠実な再現を行う場合は、論文のどの要素と評価手順を実装するのかを明示します。UltraBERTの事前学習全体の再現は、初期ライブラリで約束する成果物ではありません。
